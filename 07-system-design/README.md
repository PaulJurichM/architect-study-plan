# Блок 7. System Design для собеседований

Интервью по системному дизайну — отдельный жанр: за 45–60 минут спроектировать систему вслух, управляя разговором и показывая компромиссы. Блок даёт метод, оценки, строительные блоки (кэш, шардирование, поиск, хранилища) и практику на классических задачах. Знания из блоков 2 и 3 здесь применяются в формате собеседования.

## Критерий завершения блока

Решить письменно не менее восьми задач из модуля 7.6 по методу из 7.1 (с оценками, API, схемой данных и разбором узких мест) и провести минимум два пробных интервью вслух — с коллегой или с Claude в роли интервьюера.
