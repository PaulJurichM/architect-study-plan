# Прогресс

Модуль считается пройденным, когда закрыт его issue. Незакрытые модули учитываются частично — по отмеченным пунктам чек-листа в issue. Данные подтягиваются из GitHub при открытии страницы, изменения видны через пару минут.

<div id="sp-progress"></div>

<p class="sp-note">Отмечать прогресс — в самих issues: галочки в разделе «Готовность», закрытие issue — когда все четыре пункта выполнены. Вид со стороны GitHub: <a href="https://github.com/PaulJurichM/architect-study-plan/milestones">milestones</a>.</p>
