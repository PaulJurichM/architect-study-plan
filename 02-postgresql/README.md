# Блок 2. PostgreSQL изнутри

Не «что такое индекс», а как PostgreSQL хранит версии строк, что видит транзакция, кто кого блокирует и почему планировщик выбрал именно этот план. Для аналитика это требования к консистентности, к миграциям и к производительности, основанные на понимании механизма, а не на «сделайте, чтобы работало быстро».
