# Блок 9. Данные и аналитические системы

Операционные системы производят данные, аналитические системы превращают их в отчёты, прогнозы и решения. Блок о том, как устроены аналитические хранилища, как моделировать данные для анализа, как строить конвейеры и как обеспечивать качество данных. Он продолжает ваш опыт с прогнозированием спроса и отвечает на частый вопрос собеседований «как у вас устроена аналитика».

## Критерий завершения блока

Для обезличенной ритейл-сети спроектировать аналитический контур: источники, способ загрузки, слои хранилища, звёздную схему для продаж и остатков, витрину для прогноза спроса, проверки качества данных и владельцев. Схема и таблица — в «Заметках» модуля 9.5.
