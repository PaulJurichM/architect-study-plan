# Блок 5. ИИ в архитектуре систем

Как устроены системы на основе больших языковых моделей и ML: RAG, агенты и инструменты, оценка качества, безопасность, эксплуатация моделей. Отдельный модуль — как аналитику постановить ИИ-функцию так, чтобы её можно было принять и эксплуатировать. Цель блока — перейти от «настраиваю интеграции с ИИ» к «проектирую ИИ-системы и отвечаю за их качество».

## Критерий завершения блока

Спроектировать обезличенную ИИ-функцию из своей предметной области (например, ассистент аналитика по базе спецификаций): архитектура RAG или агента, требования к качеству и метрики оценки, модель угроз, стоимость одного запроса, fallback. Оформить как постановку по шаблону из модуля 5.7.
