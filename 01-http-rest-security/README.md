# Блок 1. HTTP, REST и безопасность интеграций

Что происходит между «клиент вызвал метод» и «сервер вернул 200»: сеть, шифрование, семантика протокола, аутентификация и защита API. Для аналитика это язык, на котором пишутся требования к интеграциям: таймауты, ретраи, идемпотентность, способ аутентификации, требования к сертификатам.

## Инструменты

- `curl -v`, `curl --trace-time`, `openssl s_client`, DevTools → Network (вкладка Timing).
- Wireshark — по желанию, чтобы один раз увидеть TCP- и TLS-рукопожатие глазами.
- [jwt.io](https://jwt.io) — только для учебных токенов, никогда не вставлять туда рабочие.
- Postman / REST Client в VS Code.

## Критерий завершения блока

Взять любую свою старую спецификацию интеграции (обезличенную) и переписать раздел нефункциональных требований: транспорт и TLS, аутентификация, идемпотентность, таймауты и ретраи, коды ошибок, лимиты. Результат записать в раздел «Заметки» модуля [1.5](1.5-api-security.md).
